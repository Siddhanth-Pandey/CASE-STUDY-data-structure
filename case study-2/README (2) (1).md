# Social Network Friendship Game

A small beginner-friendly Python project that demonstrates a social network using an adjacency matrix.

## How to play
- Five users are provided by the program: Alice, Bob, Charlie, David, and Emma.
- The program asks whether two users are friends.
- Enter `1` for friends or `0` for not friends.
- The program checks your answer and keeps score.

## Adjacency matrix
The program stores friendships in a matrix:
- `1` means the two users are friends.
- `0` means the two users are not friends.
- Friendship is mutual, so the matrix is symmetric.

## Run
```bash
python social_network.py
```

No extra libraries are required.
